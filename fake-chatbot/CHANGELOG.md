# Changelog

## 1.0.0 — 2026-11-20
- Copied original PowerShell WinForms fake chatbot and both external prompt sets to `legacy/` without changing the source repository.
- Added a responsive, static web chat proof of concept with editable preset responses in `data/prompts.json`.
- Added safe date/time substitutions in place of PowerShell expression execution, and whole-word/phrase keyword matching.
- Added Node built-in logic tests and a manual deployment checklist.
- Added the project to the website repository index.
