# Changelog

All notable changes to the AI Model Timeline project and every generated graphic are recorded here.

## [0.1.0] - 2026-11-23
### Added
- Initial project structure.
- One-source-of-truth model dataset design.
- Table and SVG timeline renderer driven by the same JSON.
- Immutable versioned graphic archive convention.
- Per-release data snapshots and manifest.
- SVG and PNG export naming tied to project version and creation date.

### Why
Previous manually/generated graphics could drift from the text table or introduce layout/text inconsistencies. This version establishes deterministic rendering and historical preservation.

### Graphic
No canonical historical release graphic is declared for 0.1.0. The project infrastructure is being established before the full historical dataset is source-audited.
