# jasr.me demo screenshots

Captured September 25, 2026 with the installed Playwright CLI against the deployed public pages on `https://jasr.me`. Desktop captures use a 1440×1000 viewport; mobile captures use a 390×844 Chromium viewport. Pages were opened read-only and no credentials, passwords, API keys, tokens, or production records were entered.
