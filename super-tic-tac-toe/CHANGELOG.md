# Changelog

## 1.1.0 — 2026-11-18
- Add unlimited undo and redo controls for the current game.
- Retract and restore completed results in signed-in history when undoing or redoing the final move.

## 1.0.0 — 2026-11-18
- Add responsive Super Tic-Tac-Toe and configurable 3×3–5×5 classic mode.
- Add computer play at easy, medium, and hard levels, with medium as default.
- Add optional user-management score history while keeping anonymous play available.
