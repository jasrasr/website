# Matching Game

A simple 4×4 color memory game for young children. Tap or click two blocks to reveal them. Matching colors stay visible; other blocks turn over after a short pause. Find all eight pairs to win, then press **New game** to play again.

The game is a standalone static page with no account, saved data, or build step. Open `index.html` locally or serve the `matching-game/` directory from the website.
