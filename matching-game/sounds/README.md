# Custom tile recordings

Record each word separately as an MP3 file. Keep filenames lowercase and store them under this `matching-game/sounds/` folder. The game uses your recording when it exists and falls back to the browser voice when it does not.

Open [recording-script.html](recording-script.html) in a browser for a print-friendly checklist containing every phrase and filename.

## Colors

Store these in `matching-game/sounds/colors/`:

`red.mp3`, `orange.mp3`, `yellow.mp3`, `green.mp3`, `teal.mp3`, `blue.mp3`, `purple.mp3`, `pink.mp3`, `brown.mp3`, `lime.mp3`, `navy.mp3`, `coral.mp3`, `mint.mp3`, `violet.mp3`, `gold.mp3`, `sky-blue.mp3`, `magenta.mp3`, `gray.mp3`

Example: `matching-game/sounds/colors/red.mp3`

## Letters

Store `a.mp3` through `z.mp3` in `matching-game/sounds/letters/`.

Example: `matching-game/sounds/letters/a.mp3`

## Numbers

Store `1.mp3` through `18.mp3` in `matching-game/sounds/numbers/`.

Example: `matching-game/sounds/numbers/1.mp3`

## Objects

Store these in `matching-game/sounds/objects/`:

`apple.mp3`, `banana.mp3`, `ball.mp3`, `car.mp3`, `train.mp3`, `airplane.mp3`, `teddy-bear.mp3`, `book.mp3`, `pencil.mp3`, `cup.mp3`, `key.mp3`, `clock.mp3`, `star.mp3`, `flower.mp3`, `tree.mp3`, `dog.mp3`, `cat.mp3`, `house.mp3`

Example: `matching-game/sounds/objects/apple.mp3`

Short recordings work best. Trim silence from the start so the word plays as soon as a tile is revealed.
